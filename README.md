# Brilio website

Marketing site for Brilio (brilioclean.com), a Chicago cleaning company: residential, Airbnb/short-term rental, commercial, and floor care.

Plain static HTML/CSS/JS, no build step on Vercel. Every push to `main` deploys to production.

## Editing pages

The HTML pages, `sitemap.xml`, and `robots.txt` are generated by `tools/build.py`, which holds the shared header, footer, quote form, and each page's copy. Edit it, then regenerate and commit the output:

```sh
python3 tools/build.py .
```

Styles live in `styles.css`; the quote form script is `site.js`.

## Quote form

The form posts to FormSubmit (formsubmit.co), which emails each request to info@brilioclean.com. The first submission sends an activation email to that inbox that must be confirmed once.

## Local preview

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000. Locally, service pages need the `.html` suffix (Vercel's `cleanUrls` serves them without it).
